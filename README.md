# 数据分析与财务建模项目集

你好！本仓库包含我在数据分析与财务建模方向独立完成的两个实战项目。点击下方文件夹即可查看详细代码与说明文档：

## 📂 项目一：Maotai-Financial-Project（贵州茅台财务数据自动化分析）
- **核心技术**：Python (Pandas, akshare, Matplotlib), SQLite
- **项目简述**：自动化抓取白酒龙头（贵州茅台）历年真实财报，处理错位表头与空值清洗，并完成核心指标可视化。

## 📂 项目二：Retail-SQL-Project（零售业务 SQL 建模与业务洞察）
- **核心技术**：Python, SQL (窗口函数, 聚合), SQLite
- **项目简述**：构建 5000 条零售业务数据库，编写高级 SQL 查询计算客单价、复购用户，并使用 Python 生成数据看板。
